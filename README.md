# 馬の手帖 ver.2.4 — HORSE NOTES

日本語の競馬メモ閲覧PWAです。静的HTML・CSS・JavaScriptだけで動作します。

- 馬名検索・レース名検索、時系列メモ、次走チェックポイント
- 「レース総括」「予想段階」「すべて」の切り替え
- CSV取り込みと端末のブラウザー内保存
- Google Identity Servicesによる読み取り認可とSheets APIからの手動取得
- iPhoneのSafariからホーム画面への追加

同梱する馬・レース・見解はすべて架空のサンプル（6頭・12件）です。実際のCSVは含みません。

## 利用方法

公開サイトをSafariで開き、共有メニューから「ホーム画面に追加」を選びます。「ウェブアプリとして開く」があればオンにします。追加したアイコンからアプリを開いた後、「CSVを取り込む」で端末のCSVを選んでください。

標準列：

```text
馬名,記録日,レース,観察・レース内容,当時の評価・仮説,次走チェックポイント,次走注目,記録者,出典チャット,記録種別,備考,本人の見解,チャッピーの見解,レース開催日
```

N列「レース開催日」は任意で、`YYYY-MM-DD` 形式です。従来のA〜Mの13列だけでも取り込めます。列名で対応を判定し、列の並べ替えや未使用の追加列も保持します。

「要確認」などの日付や空欄も原文を保持します。「本人の見解」「チャッピーの見解」は別々に表示します。新しいCSVの取り込みは以前の取り込み内容全体の置き換えです。

## 保存と通信

アプリと架空のサンプルはホスティング先から配信されます。CSVはブラウザー内で読み込み、localStorageに保存します。Google連携を設定するとGoogle公式の認証ライブラリーを読み込みます。ボタン操作による読み取り認可後、Sheets APIから指定の表を取得します。認可トークンはメモリーにだけ保持し、端末の永続保存・公開ファイル・ログに書き出しません。CSV本文・メモを外部にアップロードする処理や、表への書き戻しはありません。

## Google連携の設定

`google-config.js` の `clientId` にウェブアプリケーション用のOAuthクライアントID（末尾 `.apps.googleusercontent.com`）を設定します。このIDは公開用の識別子です。クライアントシークレットは使用しません。設定エリアから端末ごとにIDを保存する方法も使えます。端末側に保存したIDがあれば、設定ファイルのIDより優先します。

接続先は「馬メモ一覧」のA1:Nです。シートの共有は「制限付き」にし、利用するGoogleアカウントに閲覧権限を付けてください。「設定 · Googleスプレッドシート連携」→「接続」→「最新データを取得」で更新できます。認可はボタン操作時にだけ行い、起動時には保存データを表示します。認証・通信・検証・保存に失敗した場合は以前のデータを維持します。

CSVとSheetsのデータを結合せず、成功した取得内容で保存データ全体を置き換えます。取得元と最終更新日時は設定エリアに表示します。「接続解除」は保存済みのメモを消しません。Google側の許可取消が確認できなかった場合は、その旨を表示します。

使用するOAuthスコープは `https://www.googleapis.com/auth/spreadsheets.readonly` のみです。この権限は、認可したアカウントがアクセスできるスプレッドシート全体の読み取りを許可します。対象の表とA〜N列だけを取得するのはアプリの処理による制限です。ファイルや列単位のOAuth権限ではありません。

Google Cloudの承認済みJavaScript生成元に公開サイトのオリジンを登録してください。ローカル確認時にはlocalhostの生成元登録も必要です。iPhoneのホーム画面アプリでは、Googleの認証画面から戻れることを実機で確認してください。動作しない場合でもCSVと保存メモは利用できます。

PC版・iPhone版、別のブラウザー・ホーム画面アプリでは保存場所が異なることがあります。各端末でCSVを取り込むかGoogleから取得してください。サイトデータの削除やアプリ削除等で保存内容を失うことがあるため、元CSVを保管してください。ver.1の保存データは読み継ぎ、新しい保存先に更新します。ver.1の保存キーは削除・上書きしません。

初回にアプリ本体のキャッシュが完了すると、オフラインでの閲覧にも対応します。iPhone実機での最終確認は公開後に行ってください。

## ver.2.3 のレース名検索

## ver.2.4 注目度カラー

馬のシルエットは従来の文字「♞」のままです。形・書体・サイズ・位置を変えず、赤（最優先）・緑（注目）・青（通常）・虹（絶対買う！）で次走への注目度を表示します。虹は文字内部へのCSSグラデーションで、絵文字や別イラストは使いません。ヘッダー・フッターのブランドアイコンは馬に紐づかないため従来どおりです。レース検索の登録馬にも同じ既存シルエットを表示します。

自動判定は記録日の新しい順でG列「次走注目」が空欄でないメモを探します。「最優先」は赤、「注目」は緑、「通常」「未確認」・その他・該当なしは青です。最新の非空欄が未確認や未知の文字列なら、古い赤・緑へは戻りません。日付不明は既存の並び順（判定できる日付の後、元の行順）に従い、日付を推測しません。虹は手動設定専用です。

プロフィールのシルエットだけをタップすると、自動→青→緑→赤→虹→自動と切り替えます。ボタンはEnter/Spaceで操作でき、現在のモード・評価と次の変更を読み上げます。表示カードは色を共有しますが、カード内で変更はできません。

手動設定は独立した `horse-notes-attention-v1` に保存し、識別子は既存の馬名集約と同じNFKC正規化＋空白除去の馬名です。CSV/Sheets更新で行IDや順番が変わっても維持し、自動に戻すとその馬の手動項目だけを解除します。手動中は取得元より優先、自動復帰時は最新の評価を表示します。出走後の自動リセットやお気に入り機能、Google Sheetsへの書き込みは実装しません。

読み込み失敗時は元の保存内容を変更せず自動表示で閲覧を続行し、プロフィールに通知します。読み込めない設定を勝手に上書きしないため、その状態での手動変更も保存しません。書き込み失敗時は変更前の注目度を維持して通知します。メモ・Google設定の保存先は変更しません。アセットとService Workerはver.2.4へ更新します。
