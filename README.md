# 馬の手帖 ver.1 — HORSE NOTES

日本語の競馬メモ閲覧PWAです。静的HTML・CSS・JavaScriptだけで動作します。

- 馬名検索、時系列メモ、次走チェックポイント
- 「レース総括」「予想段階」「すべて」の切り替え
- CSV取り込みと端末のブラウザー内保存
- iPhoneのSafariからホーム画面への追加

同梱する馬・レース・見解はすべて架空のサンプル（6頭・12件）です。実際のCSVは含みません。

## 利用方法

公開サイトをSafariで開き、共有メニューから「ホーム画面に追加」を選びます。「ウェブアプリとして開く」があればオンにします。追加したアイコンからアプリを開いた後、「CSVを取り込む」で端末のCSVを選んでください。

標準列：

```text
馬名,記録日,レース,観察・レース内容,当時の評価・仮説,次走チェックポイント,次走注目,記録者,出典チャット,記録種別,備考,本人の見解,チャッピーの見解
```

「要確認」などの日付や空欄も原文を保持します。「本人の見解」「チャッピーの見解」は別々に表示します。新しいCSVの取り込みは以前の取り込み内容全体の置き換えです。

## 保存と通信

アプリと架空のサンプルはホスティング先から配信されます。CSVはブラウザー内で読み込み、localStorageに保存します。CSV本文・メモを送信する処理、サーバーへの保存、Googleへの接続、端末間同期はありません。元のCSVは書き換えません。

PC版・iPhone版、別のブラウザー・ホーム画面アプリでは保存場所が異なることがあります。各端末でCSVを取り込んでください。ホーム画面アプリへの追加後に取り込むと分かりやすく使えます。サイトデータの削除やアプリ削除等で保存内容を失うことがあるため、元CSVを保管してください。

初回にアプリ本体のキャッシュが完了すると、オフラインでの閲覧にも対応します。iPhone実機での最終確認は公開後に行ってください。

## GitHub Pages設定

このフォルダーの内容をリポジトリーの最上位に置き、Settings → Pages → Deploy from a branch → main → /(root) を選びます。ビルドや依存パッケージのインストールは不要です。

このリポジトリーに実データやCSVをアップロードしないでください。
