# 馬の手帖 ver.2.1 — HORSE NOTES

日本語の競馬メモ閲覧PWAです。静的HTML・CSS・JavaScriptだけで動作します。

- 馬名検索、時系列メモ、次走チェックポイント
- 「レース総括」「予想段階」「すべて」の切り替え
- CSV取り込みと端末のブラウザー内保存
- Google Identity Servicesによる読み取り認可とSheets APIからの手動取得
- iPhoneのSafariからホーム画面への追加

同梱する馬・レース・見解はすべて架空のサンプル（6頭・12件）です。実際のCSVは含みません。

## 利用方法

公開サイトをSafariで開き、共有メニューから「ホーム画面に追加」を選びます。「ウェブアプリとして開く」があればオンにします。追加したアイコンからアプリを開いた後、「CSVを取り込む」で端末のCSVを選んでください。

標準列：

```text
馬名,記録日,レース,観察・レース内容,当時の評価・仮説,次走チェックポイント,次走注目,記録者,出典チャット,記録種別,備考,本人の見解,チャッピーの見解
```

「要確認」などの日付や空欄も原文を保持します。「本人の見解」「チャッピーの見解」は別々に表示します。新しいCSVの取り込みは以前の取り込み内容全体の置き換えです。

## 保存と通信

アプリと架空のサンプルはホスティング先から配信されます。CSVはブラウザー内で読み込み、localStorageに保存します。Google連携を設定するとGoogle公式の認証ライブラリーを読み込みます。ボタン操作による読み取り認可後、Sheets APIから指定の表を取得します。認可トークンはメモリーにだけ保持し、端末の永続保存・公開ファイル・ログに書き出しません。CSV本文・メモを外部にアップロードする処理や、表への書き戻しはありません。

## Google連携の設定

`google-config.js` の `clientId` にウェブアプリケーション用のOAuthクライアントID（末尾 `.apps.googleusercontent.com`）を設定します。このIDは公開用の識別子です。クライアントシークレットは使用しません。設定エリアから端末ごとにIDを保存する方法も使えます。端末側に保存したIDがあれば、設定ファイルのIDより優先します。

接続先は「馬メモ一覧」のA1:Mです。シートの共有は「制限付き」にし、利用するGoogleアカウントに閲覧権限を付けてください。「設定 · Googleスプレッドシート連携」→「接続」→「最新データを取得」で更新できます。認可はボタン操作時にだけ行い、起動時には保存データを表示します。認証・通信・検証・保存に失敗した場合は以前のデータを維持します。

CSVとSheetsのデータを結合せず、成功した取得内容で保存データ全体を置き換えます。取得元と最終更新日時は設定エリアに表示します。「接続解除」は保存済みのメモを消しません。Google側の許可取消が確認できなかった場合は、その旨を表示します。

使用するOAuthスコープは `https://www.googleapis.com/auth/spreadsheets.readonly` のみです。この権限は、認可したアカウントがアクセスできるスプレッドシート全体の読み取りを許可します。対象の表とA〜M列だけを取得するのはアプリの処理による制限です。ファイルや列単位のOAuth権限ではありません。

Google Cloudの承認済みJavaScript生成元に公開サイトのオリジンを登録してください。ローカル確認時にはlocalhostの生成元登録も必要です。iPhoneのホーム画面アプリでは、Googleの認証画面から戻れることを実機で確認してください。動作しない場合でもCSVと保存メモは利用できます。

PC版・iPhone版、別のブラウザー・ホーム画面アプリでは保存場所が異なることがあります。各端末でCSVを取り込むかGoogleから取得してください。サイトデータの削除やアプリ削除等で保存内容を失うことがあるため、元CSVを保管してください。ver.1の保存データは読み継ぎ、新しい保存先に更新します。ver.1の保存キーは削除・上書きしません。

初回にアプリ本体のキャッシュが完了すると、オフラインでの閲覧にも対応します。iPhone実機での最終確認は公開後に行ってください。

## GitHub Pages設定

このフォルダーの内容をリポジトリーの最上位に置き、Settings → Pages → Deploy from a branch → main → /(root) を選びます。ビルドや依存パッケージのインストールは不要です。

このリポジトリーに実データやCSVをアップロードしないでください。

## ver.2.1 のUI

ヘッダーの更新アイコンでGoogle Sheetsの取得、☰メニューでGoogle連携設定・CSV取り込み・表示データ切り替えを行います。取得中は回転表示と操作抑止、成功・失敗はヘッダー直下のメッセージで確認できます。未設定の場合は設定画面を開きます。

iPhone向けに `viewport-fit=cover` と `env(safe-area-inset-*)` を使い、ステータスバー領域をヘッダー内の余白として確保します。保存キー・保存形式・PWAのIDと公開パスは従来どおりです。

### UI回帰確認

Playwright（Node.js）とChromiumが利用できる環境で、リポジトリをローカルHTTP配信してから `node tests/ui.cjs` を実行します。既定URLは `http://127.0.0.1:8765`、ブラウザーは `/usr/bin/chromium` です。`BASE_URL` と `CHROMIUM_PATH` で変更できます。アプリ本体への依存パッケージ追加は不要です。

テストは隔離したブラウザー内で架空CSVとGoogle APIのモックだけを使います。320〜1280pxの表示、メニュー、検索・フィルター、CSV取り込み、v1/v2保存復元、オフライン閲覧、Sheets取得中・成功・403失敗時のデータ保持を確認します。

iPhone実機ではホーム画面から起動し、縦横画面のsafe-area、Google認可画面からの復帰、更新後の再起動、オフライン閲覧を最終確認してください。
